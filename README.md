# mod-vril-paths
AzerothCore Eluna **Vril Paths** (subclass, forge, AIO panel). Playerbots skipped.

Requires **mod-eluna** and **AIO**. Client: FamVril addon (optional; gossip still works).
Items 916000-916619 (armor) and path weapons live in `item_template` + Item.dbc on the family realm.

Copy `lua_scripts/` into the worldserver Lua folder. Not a C++ module.
